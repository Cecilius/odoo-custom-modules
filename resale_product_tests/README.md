# Resale Product Tests

Records functional tests of second-hand products and shows the latest result.

## Features

- *Product Tests* tab on the product form: dated test entries with result,
  tester and notes.
- **Last Test Result** on products and variants (stored on variants so it can
  be searched, grouped and exported).
- Configurable test outcomes (*No issue*, *Issues found*, *Not working*,
  *Needs repair* by default), editable by *Resale / Administrator* only.
